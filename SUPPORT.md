# Supporto

- **Domande e proposte**: apri una discussione nella scheda **Discussions** del
  repository.
- **Problemi**: apri una issue nella scheda **Issues** usando uno dei modelli.
- **Vulnerabilità**: segui [SECURITY.md](SECURITY.md) e usa la segnalazione
  riservata.
- **Contributi**: leggi [CONTRIBUTING.md](CONTRIBUTING.md).

Prima di scrivere, controlla il `README.md` e le issue già presenti. Il
progetto è mantenuto nel tempo libero: le risposte possono non essere
immediate.

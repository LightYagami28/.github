# File predefiniti della community

Questo repository contiene i file di comunità che GitHub applica ai repository dell'account che
non ne hanno uno proprio: [codice di comportamento](CODE_OF_CONDUCT.md),
[guida ai contributi](CONTRIBUTING.md), [politica di sicurezza](SECURITY.md),
[supporto](SUPPORT.md), modelli di issue, di pull request e di discussione.

Un repository che contiene un file con lo stesso nome usa il proprio e ignora questo.

| Percorso | Cosa è |
| --- | --- |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1, in italiano |
| `CONTRIBUTING.md` | Flusso di lavoro per le modifiche |
| `SECURITY.md` | Come segnalare una vulnerabilità |
| `SUPPORT.md` | Dove chiedere aiuto |
| `.github/ISSUE_TEMPLATE/` | Modelli per segnalare problemi e proporre funzioni, più `config.yml` |
| `.github/PULL_REQUEST_TEMPLATE.md` | Modello di pull request |
| `.github/DISCUSSION_TEMPLATE/` | Moduli per le categorie `ideas`, `q-a`, `announcements` |

Le licenze non si ereditano: ogni repository ha la propria.
